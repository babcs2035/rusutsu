## アイコンの意味
### コース
- ○: 全面滑走可
- △: 一部滑走可, 雪不足
- ×: クローズ

### リフト
- ○: 運行中
- △: 準備中, 待機中, 天候回復待ち
- ×: 運休

## コース詳細
### HPにおいて「上部」「下部」と分かれているもの
- geojson: `_#上部`と下部に分ける
- スプレッドシート: 上部、下部に分かれていない  

→ 地図上に表示させる時は、上部、下部を合体させて全体の「距離」「平均斜度」「最大斜度」を表示させたい。オープン状況についてはもちろん「上部」「下部」に分けるけど

### `X_#上部`, `X_#中部`, `X_#下部`
これは1本のコースとして扱う。ただし、コース内で「レベル」や「圧雪」、「オープン状況」が異なることがあるため、こうやって分けている。タップしたら一つのコースとして表示されるが、その中で状況は異なる
- スプシ: `X` or `X_#上部`, `X_#中部`, `X_#下部`
- geojson: `X_#上部`, `X_#中部`, `X_#下部`
- クローリング結果: `X_#上部`, `X_#中部`, `X_#下部`or `X`
- 実際の表示予定: `X` (地図上では1本のコースとして表示する)

(注) `X_上部`などと`#`がない場合は, コース名に単に「上部」と入っていただけ。処理の都合でjson上では`_`をつけているが, 実際の表示では`X上部`と表示させる予定。

### `X_2`, `X_迂回`, ...
同じコース名で別のルートがある場合に`_2`, `_迂回`などをつけている。
- スプシ: `X_2`, `X_迂回`, ...
- geojson:`X_2`, `X_迂回`, ...
- クローリング結果: `X`
- 実際の表示予定
    - `X_2`→`X_2`
    - `X_迂回`→`X(迂回)`


### `無名_1`, `無名_連絡`, ...
ゲレンデ上にはコースがあるけど、クローリングした結果からは得られない場所。
- スプシ: `無名_1`, `無名_連絡`, ...
- geojson: `無名_1`, `無名_連絡`, ...
- クローリング: なし
- 実際の表示予定
    - `無名_1`→`無名`
    - `無名_連絡`→`連絡`

### ツリーラン
これは正しく書かないと命の危険にも繋がりそうだから、とりあえずは表示せず、ツリーランのコース以外を表示することとする。オープン状況についてはクローリングで取ってくる。
