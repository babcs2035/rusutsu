# article.jsonの箇条書きの書き方

## 完成形の見本

`beginner` の1カテゴリを、画面に出る形で示す。文の長さ、細かさ、やわらかさをここに合わせる。

> **良い点**
>
> - 山麓側に幅広く緩やかな独立したコースがあり、初めて板を履く段階から安心して繰り返し練習できます。
> - 滑れるようになった後は、中腹の距離と斜度が少し増す初中級斜面へ進めるため、段階的に上達できます。
> - 雪遊び用の区画と動く歩道もあります。
>
> **気になる点**
>
> - 駐車場やシャトルバスの降車地点からアクセスリフトまで、坂道を含む徒歩と用具運搬が必要で、子ども連れや初心者には負担になる場合があります。
> - 休日は山麓の初心者用斜面とリフトが混みやすく、離れたエリアへ移る際にも体力を使います。
>
> **代表的なコース**
>
> - 豪円山エリア：幅広く凹凸の少ない緩斜面で、初滑りや家族での繰り返し練習に適しています。
> - 中の原エリア：下部は初心者も利用しやすく、豪円山から次の段階へ進む際に使えます。
> - U1コース：幅に余裕のある初中級斜面で、ターンを覚えた後に少し難しい斜面へ進む際に向いています。
> - タカぴよランド：動く歩道があり、そりや雪遊びを楽しむ小さな子どもに便利です。

見本から読み取ること。

- 1項目が20〜70字ある。事実を切り詰めて短くしていない。
- どの項目も「何があるか」で終わらず、「誰が、どの段階で、どうなるか」まで書いてある。
- 良い点・気になる点にコース名がない。位置（山麓側、中腹）と人（初めて板を履く段階、
  子ども連れ）で書いてある。
- コース名は「代表的なコース」にだけある。
- リフト、駐車場、シャトルバス、動く歩道など、斜面以外の話も入っている。

## detail.json からの作り方

`detail.json` の `reason` から `article.json` の `reason` を作る流れを、志賀高原中央エリアの
`beginner` で示す。

### 入力（detail.json の reason 抜粋）

> 初心者はかなり強い。特に一の瀬ファミリーの天狗コースについて、2026年2月の子連れ口コミでは
> 「下の方は練習にもってこい」、山頂からも天狗コースなら比較的なだらかと評価されている。
> 2025-26年末年始に7歳・11歳の子どもと滑った家族も、3.2kmの天狗コースを何度も反復し
> 「スキー初級者は滑りやすい」と記録している。（略）蓮池についても長年志賀を滑る利用者が、
> 緩斜面中心で初心者・初級者に良く、人も多くないと評価する。弱点は、一の瀬正面上部は急斜面
> なので初心者が直滑降で上から下まで行く構成ではなく、天狗への迂回が重要なこと、団体講習と
> 重なると一の瀬・高天ヶ原周辺が混みやすいこと。

### 落とすもの

- 「2026年2月の子連れ口コミでは」「2025-26年末年始に7歳・11歳の子どもと」→ 調査の話
- 「〜と評価されている」「〜と記録している」→ 引用であることの表明
- 「複数媒体で繰り返し高評価されており〜◎とした」→ 採点の理由

### 残るもの（事実と、それが意味すること）

| 事実 | 読み手にとっての意味 |
| --- | --- |
| 山麓の正面下部は幅が広い | 初めての練習を繰り返せる |
| 山頂からも緩やかな林間コースがある | 上達後は山頂まで行動範囲を広げられる |
| 正面上部は急斜面 | 山頂から直接下りられず、迂回を覚える必要がある |
| 団体講習の時間は混む | 時間帯によっては練習量が落ちる |

### 出力（article.json の reason）

```json
[
  {
    "label": "good",
    "text": "山麓の正面ゲレンデ下部は幅が広く、初めて板を履く段階から人を避けずに繰り返し練習できます。"
  },
  {
    "label": "good",
    "text": "滑れるようになると、山頂から麓まで続く緩やかな林間コースへ進めるため、行動範囲を一気に広げられます。"
  },
  {
    "label": "bad",
    "text": "正面ゲレンデの上部は急斜面なので、山頂から下りるには林間コースへの迂回を覚える必要があります。"
  },
  {
    "label": "bad",
    "text": "団体講習が入る時間帯は山麓の緩斜面とリフトが混み合い、練習の回数を稼ぎにくくなります。"
  }
]
```

コース名（天狗コース）は出てこない。`courses` に入る。

```json
[
  {
    "name": "一の瀬ファミリー 天狗コース",
    "description": "山頂から山麓まで続く3.2kmの林間コースで、斜度が終始緩いため、初級者が長い距離を滑る最初の一本に向いています。"
  }
]
```

## カテゴリごとに読み手が知りたいこと

| カテゴリ | 優先する事実 |
| --- | --- |
| `beginner` | 麓だけか山頂からも下れるか。狭い所、平らな所、混雑、次の段階へ進めるか |
| `intermediate` | 圧雪中斜面はいくつあるか。長いか。別の場所への移動は必要か |
| `advanced` | 圧雪急斜面はいくつあるか。ほかの上級斜面はコブや非圧雪か |
| `moguls` | コブはいつもあるか。どこまで続くか。何本あるか |
| `powder` | 非圧雪斜面はどこにいくつあるか。朝の競争や開放条件はどうか |
| `tree-run` | 公式区域か。申請や受付が必要か。閉鎖条件と出口はどうか |
| `park` | 何があるか。難度別に分かれるか。いつ開くか |

どのカテゴリでも、リフト、移動、駐車場、受付、混雑など、当日の動きに関わることは書いてよい。

## text の書き方

- 20〜70字を目安にした、独立した敬体の1文。句点で終える。
- 事実と、それが読み手にとって何を意味するかをつなぐ。事実だけで止めない。
- 前の項目を読まなくても意味が通る。`そのため` `一方` `ただし` `また` `さらに` `なお` で
  始めない。`これ` `それ` `前者` `後者` で前を参照しない。
- エリアの位置、段階、人、リフト、距離、本数は使ってよい。コース名は使わない。
- 調査年、媒体名、URL、引用文、レビュー件数は書かない。

### 書き直しの例

| 直す前 | 問題 | 直した後 |
| --- | --- | --- |
| 圧雪された急斜面は1本だけです。 | 事実で止まっている | 圧雪された急斜面は1本に限られるため、上級者だけで行くと半日で滑り尽くします。 |
| コブの物量があります。 | 様子も意味も分からない | コブは斜面の上から下まで途切れず続くので、1本で足を使い切れます。 |
| 中級斜面でカービングを反復できます。 | カテゴリ名から分かること | 中斜面は距離があり、一度も止まらずに麓まで下りられます。 |
| ジャイアントゲレンデは急な圧雪斜面です。 | コース紹介（`courses` の内容） | 上級者向けの急斜面は毎日圧雪されるため、荒れを気にせず攻められます。 |
| 中央エリア全体を滑るには、ゲレンデ間の移動が多くなります。 | 事実で止まっている | 端から端まで滑るにはリフトの乗り継ぎが続くので、1日で全部回ろうとすると滑走時間が削られます。 |

## label

| label | 使う場面 |
| --- | --- |
| `good` | 行き先として選びやすくなること |
| `bad` | 行き先として選びにくくなること、手間、制限 |
| `description` | 良し悪しを決めない地形や営業条件 |

文が肯定形か否定形かではなく、来場判断への影響で決める。申請、受付、営業時間の短さ、閉鎖は
`bad`。積雪によってコブの形が変わるだけなら `description`。

## full

3〜5項目。7カテゴリの網羅ではない。全体の来場判断を最も大きく変えることだけを選ぶ。

- 長さ、コース数、範囲など、最も目立つ特徴
- 移動、混雑、申請、営業時間など、旅行計画を変える制約
- 必要な場合だけ、目的の斜面や設備がないこと

## reason

2〜5項目。良い点と気になる点の両方を残す。

| score | 書く内容 |
| --- | --- |
| `◎` | コース数、長さ、営業の安定など、ほかと比べて目立つこと |
| `○` | できることと、コース数の少なさや条件による制約 |
| `△` | 対象がない、または目的にするには足りないこと |

`warn: true` で不確かさが来場判断に影響するときだけ、分からない内容を1項目にする。
調査件数や媒体は書かない。

## courses

`detail.json` の `courses` にあるコースだけを使う。`description` は25〜70字。

**どんな斜面か＋誰が、どの段階で使うか** を書く。斜面の寸法だけで終わらせない。

悪い例:

```json
{ "name": "サンプルコース", "description": "カービングを何度も楽しめる中級コースです。" }
```

```json
{ "name": "サンプルコース", "description": "全長1,200mで平均斜度は14度です。" }
```

良い例:

```json
{
  "name": "サンプルコース",
  "description": "幅に余裕のある初中級斜面で、ターンを覚えた後に少し難しい斜面へ進む際に向いています。"
}
```
