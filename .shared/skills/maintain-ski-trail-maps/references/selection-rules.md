# どのマップを登録するか（判断基準）

担当エージェントと親が同じ基準で選ぶための決まり。迷ったら下の「人に聞くとき」に回す。

## 1スキー場に1枚

- `mapUrls` は **1スキー場につき1枚**。2枚以上登録されていたら、見やすい1枚に絞る。
- 統合した施設（統合元IDのリンクも詳細画面にまとめて出る）も、まとめた結果が1枚になるようにする。
- 山ごと・エリアごとに別の図しか無く、どれか1枚では全体が分からないときは、全体図を探す。全体図が無ければ人に聞く。

## 見やすさの優先順（上ほど強い）

1. **そのスキー場の現行シーズンの公式マップ**であること。運営会社・自治体・観光協会など公式の掲載に限る。
   ガイドサイト・ブログ・SNSの転載は使わない。
2. **コース名が図の中に書いてある**こと。コース番号だけで凡例が別ページの図より、名前が入った図を採る。
   例: 星野リゾート トマム。`course-map01.png`（番号だけ）より `map2025.pdf`（コース名入り）。
   この基準は下の「画像を優先」より強い（名前入りがPDFしか無ければPDFを採る）。
3. 全体が1枚に入っていること（一部エリアの拡大図・夏の図・園内全体図より、スキー場全体のゲレンデ図）。
4. 文字が読める解像度（長辺1500px以上が目安）。小さい図しか無ければそれを採り、`map-small`/`map-low-res` は残す。
5. 内容が同じなら、PDFより画像（スマホのブラウザは枠内のPDFを出せないことがある）、
   webp/png/jpg の形式違いは軽い方。
6. 内容が同じで年度だけ違うなら新しい方。

## 新しいマップか古いマップか

- 年度は、図の中の表記（「2026-27」「2026/27シーズン」）→ ファイル名・URL → 掲載ページの見出しの順で根拠にする。
  ファイル名だけの年は推定なので、図の中で確かめられなければ説明文に「年度表記なし」と書く。
- 掲載元から登録中の図が消え、同じ作りの図が新しいURLで載っていたら差し替える（`replace-map`）。
- 同じURLのまま中身が変わった（`map-content-changed`）だけなら、URLはそのまま。寸法の変化で表示が崩れないかだけ見る。
- 掲載元が消えた・トップへ転送されるときは、公式サイトから現在の掲載ページを探し、`mapPageUrls` も付け替える。

## 説明文（description）

- `mapUrls`: `ゲレンデマップ画像/PDF / 2026-27（図内表記）` のように、種類と年度の根拠だけを短く書く。
  年度が分からなければ `ゲレンデマップ画像/PDF / 年度表記なし`。
- `mapPageUrls`: `ゲレンデマップ掲載ページ`。

## 人に聞くとき（`needs-human`）

次のときは自分で決めず、決定ファイルに `action: "needs-human"` と質問・候補URLを書く。親がまとめてユーザーに聞く。

- 2枚以上の候補があり、上の優先順でも1枚に決まらない（例: 山ごとに別の図しか無い、名前入りの図が古く番号だけの図が新しい）。
- 難易度別・エリア別に一部のコースだけを強調した図しか無く、全コース名が入った全体図が見つからない
  （例: 網張温泉。中級・初級・上級の強調図3枚。どれか1枚を自分で選ばない）。
- 公式かどうか判断できない掲載元しか無い（運営会社の変更・閉鎖の疑いなど）。
- 図がそのスキー場のものか確信が持てない（隣接スキー場との共通図、統合前の別スキー場の図）。
- 営業していない・閉鎖したように見える。

質問には、比べた候補のURLと掲載ページのURLを必ず添える（各行にURL）。
