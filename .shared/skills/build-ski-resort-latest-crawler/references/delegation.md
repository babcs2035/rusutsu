# 軽量モデルへの委譲

目的は、長い資料の読み取りを小さな担当に分け、親の入力と重複調査を減らすこと。検証項目は省略しない。この方針はこのクローラースキルの実行時に適用し、全体のモデル設定は変更しない。

## 担当の切り方

| 作業 | 担当と設定 | 渡す入力・返す成果 |
| --- | --- | --- |
| 保存済みの現行DOMの棚卸し | Luna / medium | 指定HTML → カテゴリの掲載有無、セレクター、生値、件数、根拠位置 |
| 保存済みの冬季DOMとの差分 | Luna / medium | 現行・冬季HTMLと台帳 → 名称・件数・状態記号・季節限定欄の差分 |
| 検証結果の照合 | Luna / medium | DOM、結果JSON、ログ → 不一致、警告、欠けた検証。成功を推測しない |
| 条件を確定した局所実装 | 必要な場合だけ Sol / medium | 親が確定した抽出仕様、対象ファイル、型・ガイドの関連節 → 限定差分と検証結果 |
| 意味が曖昧な状態、複雑な操作・画像天気、取得範囲の確定、API反映 | 親 | 元資料を確認して判断・実行 |

表は起動するエージェントの一覧ではない。1体へ関連する棚卸しをまとめ、独立した大きな資料がある場合だけ2体に分ける。親が資料の保存と対象の切り分けを行い、子の調査中は型・既存クローラーの確認など別作業を進める。親が同じ棚卸しを並行してやり直さない。

子は基本的に読み取り専用とし、コード編集を任せる場合は所有ファイルを1体に限定する。親も完了までそのファイルを編集しない。台帳の確定は最終コードのソースハッシュが決まってから親が行う。API保存・現在値の確認と、共有の型チェックは親がまとめて実施する。子に同じチェックを重複実行させない。

## 起動時に渡す情報

`collaboration.spawn_agent` が利用できる環境では、次のようにモデルと推論量を明示する。これは呼び出しの例であり、スキルを読むだけでプロセスが起動するわけではない。

```json
{
  "task_name": "dom_inventory",
  "model": "gpt-6-luna",
  "reasoning_effort": "medium",
  "fork_turns": "none",
  "message": "下記の担当・入力・制約・成果物を指定する"
}
```

`message` には次を具体的に埋める。会話履歴や巨大HTMLを貼り付けない。

- スキー場ID、ユーザー指定の公式URL、今回の担当と完了条件。
- 読むHTML・JSON・ログのパス、必要なガイドの節。編集担当にだけテンプレート・型・utilsの関連箇所と承認済みの抽出仕様を渡す。
- 現行／アーカイブの区別、アーカイブ日時。指定資料以外のURL探索・再取得・API送信・再委譲はしない。
- 不明は不明とする。空欄の状態は `null`、DOM消失は空欄と区別し、未知状態は生値と警告要否を報告する。冬季値を現行値へ流用しない。
- 読み取り専用か、編集してよいファイルの明示。必要な作業ファイルは `src/private/data/resorts-temporary/tmp/<resort-id>-audit/` の担当別ファイルへ保存する。秘密値を読み出したり報告へ含めたりしない。
- 返答は目安1,200字以内の要約と根拠パス。全名称・全状態など長い一覧は指定の成果物に残し、要約から省いても証拠から削らない。

成果物には「出典URL・日時・ファイル」「カテゴリ別の掲載あり／掲載なし／値なし」「名前・生値・件数」「セレクターと短い引用または行番号」「失敗・未確認」を含める。意味の推測を確認済みの事実として返さない。

## 統合と打ち切り

親は要約から、掲載カテゴリの漏れ、空欄とDOM取得失敗の混同、未知値、現行と冬季の混同を確認する。状態変換の根拠・警告・不一致は該当DOMや公式凡例まで戻って確認する。子の要約は、同じクローラー経路による実行検証やAPIのrun確認の代わりにはならない。

不足があれば同じ子へ具体的な追加確認を1回依頼する。それでも解けない意味の判断や実装問題は親が引き取る。新しい子を繰り返し起動しない。Lunaで複雑な読解が必要なら `high` を選べるが、曖昧な営業状態を推測で解決させない。

指定モデル・委譲ツールが使えない場合は親が続行し、軽量モデルを使えなかった旨を報告する。高価なモデルを暗黙に継承させて「低コスト化済み」としない。

費用の比較には親と子の両方の入力・出力・再試行を含める。利用量を取得できる場合だけ記録し、取得できなければ未計測とする。API単価をそのまま契約プランの利用枠へ換算しない。
