# 種類ごとの載せ方

種類の一覧と並び順の正本は `src/features/resort-links/linkTypes.json`。ここでは、このSkillが集める種類について
「何のページを載せるか」「ラベルをどう付けるか」「迷いやすい境目」を書く。

## 共通

- **1つの欄＝1つの役割。** 同じページが複数の種類にあたるときは、種類ごとに別の項目として書き、`quote` を変える。
- **`label`** は、同じ種類に複数あるときの短い名前（出発地・店名・駐車場名・パーク名・サービス名）。1件だけなら付けない。
- **`quote`** は、そのページで該当の内容が始まる場所の短い文字列（見出しなど、ページ本文にそのままある2〜40文字）。
  飛び先を決める手がかりで、ページ全体がその内容なら書かない。場所を CSS で指せるときは `selector` でもよい。
  その内容の始まりにある見出しを選ぶ。一覧の各行に繰り返し出てくる言葉（「特典」「料金」など）は、途中の行に着くので使わない。
  同じ id が何か所にもあるページでは `selector` が別の場所を指すので、見出しの文字で指す。
- **`note`** は、利用者に役立つ一言だけ（「冬は無料」「要予約」「山頂・ベースの2地点」）。画面ではリンクの横に1行で出るので20字ほど、長くても40字まで。
  `found` 以外の項目では、無い・調べきれない理由を書く。調査の経緯は `notes`（ファイル全体のメモ）へ。
- **`label`** も画面ではチップの文字になる。40字まで。
- **`foundOn`** は、公式サイト以外のURLを載せるとき、そのリンクが張られていた公式ページ。
- **今季の情報を載せる。** 古いシーズンのページしか無ければ `note` にシーズンを書く。
- **状態**: `found`＝ある。`none`＝公式サイトを見たうえで無い（パークが無いスキー場のパーク情報など）。
  `unchecked`＝調べきれていない（理由を `note` に）。無いと言い切れないときは `unchecked`。

## ゲレンデ

| 種類 | 載せるページ | ラベル |
| --- | --- | --- |
| `courseInfo` | コースの紹介（コース一覧・難易度・距離など）。紹介ページが無く、マップ掲載ページだけのときはそれを載せ、`note` に「コース紹介はマップのページ」と書く | エリアごとにページが分かれるときはエリア名 |
| `parkInfo` | スノーパーク（キッカー・ジブなど）の紹介 | パークが複数あるときはパーク名 |
| `parkStatus` | パークの当日の状況（アイテムの設置状況など）を出している公式ページ。SNSの投稿を埋め込んで見せている公式ページも載せる。公式サイトに置き場がなくSNSだけで発信しているなら `none` | パーク名 |
| `liveCamera` | ゲレンデのライブカメラ。地点ごとにページやURLが分かれるなら地点ごと | 地点名（山頂、ベースなど） |

## 料金

| 種類 | 載せるページ | ラベル |
| --- | --- | --- |
| `officialDiscount` | 1回行くときに使える公式の割引。前売り・早割・セット券（食事付き・レンタル付き）・宿泊者割・住民割・誕生日割など | 割引の名前 |
| `pass` | 何度も使う券の案内。シーズン券、共通シーズン券、Epic・Ikon・アースホッパーなど共通パスでの利用案内 | 券の名前 |
| `externalDiscount` | 公式ページが案内している、外部サービスの販売・割引ページ（楽天チケット、アソビュー、Klook、ふるさと納税など） | サービス名 |

- リフト券の料金表・自社のWeb販売・レンタル料金は、リフト券データの担当。ここには書かない。
- `externalDiscount` には `category` を付ける。`presale`（国内の前売り・電子チケット）、`inbound`（訪日客向け: Klook・KKday・WAmazing など）、
  `membership`（会員優待）、`transport`（交通とのセット）、`furusato`（ふるさと納税）。
- スキー場自身の販売システムは別ドメインでも外部割引ではない（リフト券データのWeb購入）。
  外部サービスの名前で売っているページ（楽天チケット、アソビュー等）が `externalDiscount`。

## 施設

| 種類 | 載せるページ | ラベル |
| --- | --- | --- |
| `restaurant` | ゲレンデ内・ベースのレストラン（ゲレ食）。一覧ページに「スキー場」の節があればそこを `quote` で指す。ホテル内だけのレストランは載せない | 店ごとにページがあるときは店名 |
| `rentalShop` | レンタルの店舗案内・予約ページ（料金表はリフト券データ側） | 店名 |
| `kidsPark` | キッズパーク、そり遊び場、託児 | 施設名 |
| `onsen` | 場内・直営の温泉、日帰り入浴 | 施設名 |
| `lodging` | 直営・公式が案内する提携の宿。宿泊予約サイトの検索結果は載せない | 宿名。多いときは宿泊一覧のページ1件 |

## 車・公共交通

| 種類 | 載せるページ | ラベル |
| --- | --- | --- |
| `carAccess` | 車でのアクセス案内。出発地ごとに節やページがあれば全部載せる。ボタンやタブで出発地を切り替えるページも、選べる出発地を全部（1ページに10か所あれば10件） | 出発地（札幌、新千歳空港 など） |
| `parking` | 駐車場の案内（場所・台数・料金） | 駐車場が複数でページが分かれるときは駐車場名 |
| `transitAccess` | 電車・バス・シャトルでのアクセス案内。出発地・手段ごとに全部 | 出発地と手段（札幌（バス）など） |
| `busTimetable` | 公式ページが案内しているバス会社の時刻表ページ | 会社名と路線名 |
| `busTour` | 公式ページが案内しているツアー会社のページ | 会社名 |

- 交通は冬の運行を確かめる。冬に運休する路線・便は載せない。
- 公式ページが会社名や電話番号だけを書いていてリンクが無いなら、公式のそのページを載せる（外部を検索して補わない）。
